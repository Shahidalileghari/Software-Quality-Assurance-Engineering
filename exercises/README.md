# Exercises

Complete the exercises in each module before reading the solutions.

1. Classify tests by level and purpose.
2. Design boundary-value tests for constrained inputs.
3. Write a reproducible defect report from a supplied scenario.
4. Add tests for missing, malformed, and unauthorized API requests.
5. Refactor a brittle E2E test to use observable conditions.
6. Identify over-mocking in a sample service test.
7. Propose performance thresholds from a stated service objective.
8. Design CI gates that balance speed and confidence.
