# Solution guidance

Solutions should explain the reasoning, not merely list expected outputs. A strong submission states assumptions, identifies risk, covers normal and negative paths, and explains why the selected test level is appropriate.

Example boundary strategy for a 3–20 character field: test lengths 2, 3, 4, 19, 20, and 21; also test non-string values, whitespace-only values, and Unicode if the requirement does not restrict character classes.
