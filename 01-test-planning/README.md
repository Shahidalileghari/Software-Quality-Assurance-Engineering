# 01 — Test planning and test design

Convert requirements into testable examples. Prioritize by probability and impact of failure.

## Techniques
- Equivalence partitioning: representative values from behaviorally equivalent groups.
- Boundary-value analysis: test just below, at, and just above limits.
- Decision tables: cover combinations of conditions and outcomes.
- State-transition testing: verify allowed and forbidden state changes.
- Pairwise testing: reduce combinatorial combinations while covering pairs.
