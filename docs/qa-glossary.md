# QA glossary

- **Acceptance criteria:** Conditions a feature must satisfy.
- **Assertion:** A check that compares actual behavior with an expectation.
- **Boundary-value analysis:** Testing values at and around input boundaries.
- **Defect / bug:** A flaw in a work product that may cause incorrect behavior.
- **Flaky test:** A test whose outcome changes without a relevant product change.
- **Integration test:** Checks interactions across component boundaries.
- **Mock:** A test double with programmable behavior and often interaction expectations.
- **Regression test:** Checks that existing behavior remains correct after change.
- **Smoke test:** A small suite that checks critical system health.
- **Stub:** A test double that supplies controlled responses.
- **Test oracle:** A source used to determine expected results.
- **Verification:** Evaluating whether work products meet specified requirements.
- **Validation:** Evaluating whether the product meets user needs.
