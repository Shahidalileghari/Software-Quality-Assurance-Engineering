# Test case template

| Field | Value |
|---|---|
| ID | QA-001 |
| Title | Descriptive behavior under test |
| Requirement | Requirement or acceptance criterion |
| Priority | P0 / P1 / P2 / P3 |
| Preconditions | Required state |
| Test data | Synthetic inputs |
| Steps | Numbered, reproducible actions |
| Expected result | Observable expected behavior |
| Actual result | Filled during execution |
| Status | Pass / Fail / Blocked / Not run |
| Evidence | Safe screenshot, log, or trace reference |
