# 11 — Security and accessibility testing

Security QA should include authorization boundaries, input validation, session handling, rate limiting, sensitive-data exposure, dependency risks, and safe error responses. Coordinate security testing and obtain authorization before testing any system.

Accessibility checks should cover keyboard navigation, focus visibility, semantic structure, labels, contrast, and screen-reader behavior. Automated scans help but do not replace manual assistive-technology testing.

Exercise: create a role/permission matrix and test both allowed and denied actions.
