# Portfolio projects

## Project 1 — QA test design pack
Produce a test plan, risk register, 25 test cases, exploratory charter, and five high-quality defect reports for a fictional commerce checkout.

## Project 2 — Unit-tested utility library
Implement validation, pricing, and date utilities. Add boundary tests, property-based test ideas, and coverage analysis.

## Project 3 — REST API testing framework
Build a reusable API test harness with environment config, auth helpers, schema assertions, negative cases, and safe test data.

## Project 4 — Browser E2E automation
Automate registration, login, search, cart, and checkout in a demo application. Capture traces and screenshots on failure.

## Project 5 — Performance baseline
Model realistic traffic, run a short baseline, analyze p50/p95/p99, throughput, and errors, then propose bottleneck investigations.

## Project 6 — QA capstone
Design a CI quality pipeline for a multi-service application. Include test strategy, risk matrix, test layers, gates, artifacts, flaky-test policy, and release criteria.
